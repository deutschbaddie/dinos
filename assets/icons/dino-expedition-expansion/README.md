# Dino Expedition expansion icons

20 icons generated with the built-in image generation tool in the same style as the original Dino Expedition icons. Each PNG is 512×512, with a transparent background and centered subject occupying about 85% of the frame. Filenames match the requested UI keys.

The complete generation prompts are in `prompts.json`. The Giant Plains silhouette correction is recorded in `giant-plains-correction.txt`.

Upload status: not uploaded. Browser control returned `noWindowsAvailable` while attempting to open Creator Hub's upload form. No Roblox asset IDs have been assigned or verified for this set.

The game source and existing icon fallbacks have not been edited.
