# Dino Expedition — New Eras

21 separate PNG icons, named with the requested keys.

- 512×512 pixels, RGBA with transparent backgrounds.
- Centered visible silhouette filling approximately 85% of the longest dimension.
- Generated with built-in image_gen. Full generation and correction prompts are in prompts.json.
- Original generated images remain preserved at the paths in sources.json.

These files are ready for Roblox upload. No Roblox asset IDs have been assigned by this export.
