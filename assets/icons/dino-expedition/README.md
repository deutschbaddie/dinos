# Dino Expedition icons

Individual upload files are named `<IDS key>.png`. Each final export is a 512×512 PNG with an alpha channel and a centered subject occupying approximately 85% of the frame.

Generated with the built-in image generation tool. `prompts.json` records the shared style and individual prompts.

Upload the PNGs to Roblox yourself, then paste each image asset ID into its matching key in `src/StarterPlayer/StarterPlayerScripts/DinoExpeditionClient/Game/UI/Icons.luau`, for example `Coin = "rbxassetid://123456789"`. IDs are left empty until the images have been uploaded.

Use the image asset ID, as described in the project's `ICON_PROMPTS.md`.
